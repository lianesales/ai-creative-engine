# AI Creative Engine

Aplicativo web para transformar 9 clipes em 27 vídeos verticais usando o método 3×3×3.

## Recursos

- Combinação de ganchos, corpos e CTAs
- Geração de 27 variações
- Headlines para os primeiros segundos, recortes e CTAs fixos
- Legendas e correções com IA
- Geração de roteiros para TikTok Shop
- Integração com OpenAI e CodeKraft
- Radar Trending com Apify
- Netlify Functions para proteger as chaves de API

## Publicação

Este projeto foi preparado para o Netlify.

Após conectar o repositório ao Netlify, configure estas variáveis como secrets no escopo `Functions`:

CODEKRAFT_API_KEY=
